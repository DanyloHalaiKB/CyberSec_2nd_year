# Комп'ютерні мережі та їх захист

## Стек
- Симулятор: **Cisco Packet Tracer** — ПІДТВЕРДЖЕНО методичкою ЛР-1 (Піскозуб А.З., Тишик І.Я., НУЛП 2025). Версію уточнити.
- Аналіз: Wireshark, tcpdump
- Linux-утиліти: ip, ping, traceroute, nmap, dig

## Ключові теми
- [ ] Моделі OSI та TCP/IP, інкапсуляція
- [ ] Фізичний і канальний рівні, Ethernet, MAC, комутація
- [ ] VLAN, транки, STP
- [ ] IPv4: адресація, маски, підмережі, VLSM, CIDR
- [ ] IPv6: адресація, базова конфігурація
- [ ] Маршрутизація: статична, RIP, OSPF
- [ ] NAT / PAT
- [ ] TCP та UDP, порти, встановлення з'єднання
- [ ] Прикладний рівень: DNS, DHCP, HTTP
- [ ] ACL: стандартні й розширені
- [ ] Міжмережеві екрани, зони безпеки
- [ ] VPN, IPsec, TLS
- [ ] IDS / IPS
- [ ] Атаки: ARP-spoofing, MITM, DoS, DNS-spoofing

## Як мене вести по цій дисципліні
- Підмережі рахуємо в двійковому вигляді, поки це не стане автоматизмом.
- Кожна лаба в Packet Tracer — з переліком перевірок: що має пінгуватися, що НЕ має, і чому саме так.
- Пастки: арифметика масок і меж підмереж; порядок правил в ACL і неявний deny any; плутанина маршрутизації й комутації.

Режим допомоги за замовчуванням: **Р1 → Р2 → Р3 → Р4** (див. `00-Загальне\README.md`).
Поточний режим для цієї дисципліни: _за замовчуванням_.
