## Як мене вести по цій дисципліні
- Спершу схема й функційні залежності, тільки потім SQL.
- Кожен запит я маю спершу сформулювати словами українською, потім писати код.
- Пастки: WHERE vs HAVING; JOIN без умови → декартів добуток; NULL у порівняннях.

Режим допомоги за замовчуванням: **Р1 → Р2 → Р3 → Р4** (див. `00-Загальне\README.md`).
Поточний режим для цієї дисципліни: _за замовчуванням_.
