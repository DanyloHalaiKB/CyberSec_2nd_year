# Бази даних та знань — карта тем

Позначай: `[ ]` не розібрано · `[~]` в процесі · `[x]` можу пояснити вголос

- [ ] Реляційна модель, відношення, ключі
- [ ] ER-моделювання, зв'язки 1:1, 1:N, N:M
- [ ] Функційні залежності, нормалізація 1НФ → 2НФ → 3НФ → БКНФ
- [ ] DDL: CREATE / ALTER / DROP, обмеження цілісності
- [ ] DML: SELECT, WHERE, ORDER BY, LIMIT
- [ ] JOIN: INNER / LEFT / RIGHT / FULL, самоз'єднання
- [ ] Агрегація: GROUP BY, HAVING, віконні функції
- [ ] Підзапити, EXISTS, IN, CTE
- [ ] Індекси, план виконання запиту
- [ ] Транзакції, ACID, рівні ізоляції
- [ ] Тригери, збережені процедури, представлення
- [ ] Бази знань: факти, правила, логічний вивід
