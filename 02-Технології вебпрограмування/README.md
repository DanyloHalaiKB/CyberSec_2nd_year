# Технології вебпрограмування

## Стек — ПРИПУЩЕННЯ, підтвердити на першій парі
- Клієнт: HTML5, CSS3, JavaScript
- Сервер: PHP + MySQL (класика НУЛП); можливо Node.js
- Локальний сервер: XAMPP або OpenServer

- [ ] JavaScript: типи, функції, масиви й об'єкти
- [ ] DOM, події, делегування подій
- [ ] HTTP: методи, коди, заголовки, запит/відповідь
- [ ] Форми, валідація на клієнті й на сервері
- [ ] Сесії, cookies, автентифікація
- [ ] Робота з БД із серверного коду, підготовлені запити
- [ ] AJAX / fetch, JSON, асинхронність
- [ ] Безпека: XSS, SQL-ін'єкції, CSRF, HTTPS

## Як мене вести по цій дисципліні
- Я на кібербезпеці: до кожної теми додавай, як це ламається, а не тільки як працює.
- Пастки: валідація лише на клієнті; конкатенація SQL замість підготовлених запитів; плутанина sync/async.

Режим допомоги за замовчуванням: **Р1 → Р2 → Р3 → Р4** (див. `00-Загальне\README.md`).
Поточний режим для цієї дисципліни: _за замовчуванням_.
