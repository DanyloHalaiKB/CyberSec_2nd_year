## Як мене вести по цій дисципліні
- Найматематичніша дисципліна: пояснення має бути повним виведенням формули, а не натяком.
- Кожну задачу доводимо до числа й перевіряємо скриптом на Python.
- Пастки: біти vs символи; логарифм не за основою 2; d виявляє d−1 помилок, а виправляє ⌊(d−1)/2⌋.

Режим допомоги за замовчуванням: **Р1 → Р2 → Р3 → Р4** (див. `00-Загальне\README.md`).
Поточний режим для цієї дисципліни: _за замовчуванням_.
