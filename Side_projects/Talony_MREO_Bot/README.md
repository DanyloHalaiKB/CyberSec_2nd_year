# Talony MREO Bot

Скрипт стежить за вільними талонами на **практичний іспит** в Е-записі ГСЦ МВС (`eqn.hsc.gov.ua`) і надсилає повідомлення в Telegram. **Бронювати треба самому**: скрипт тільки повідомляє.

## Як це працює

1. Скрипт відкриває окреме вікно Chromium з власним профілем у папці `browser_profile/`. У ньому ти **один раз входиш через ID.GOV.UA**.
2. Раз на ~2,5 хв скрипт робить із цієї сторінки ті самі запити, що й сам сайт:
   - `/api/v2/equeue/departments?serviceId=49`: список ТСЦ. Поле `allowOnlineCount > 0` означає, що там є талони.
   - `/api/v2/equeue/days?...`: вільні дні в ТСЦ, де є талони.
   - `/api/v2/equeue/slots?...`: вільний час на найближчий день.
3. Повідомлення приходить лише про **нові** дати. Якщо талони зникли, а потім з'явилися знову, прийде ще одне повідомлення.
4. Коли сесія Дії закінчиться, прийде повідомлення «увійди знову». Увійди у вікні скрипта, і моніторинг продовжиться сам.

## Встановлення (Windows)

1. Встанови **Python 3.10+** з python.org і постав галочку «Add python.exe to PATH».
2. Двічі клацни `setup.bat`. Він створить `.venv`, встановить Playwright і Chromium і скопіює `config.example.json` у `config.json`.
3. **Створи окремого Telegram-бота:** у Telegram відкрий @BotFather, надішли `/newbot`, задай ім'я, і отримаєш токен. Встав його в `config.json` у поле `telegram_token`.
4. Напиши своєму новому боту `/start`, потім у консолі в цій папці виконай:
   ```
   run.bat --get-chat-id
   ```
   Отримане число встав у `telegram_chat_id`.
5. Перевір, чи доходять повідомлення: `run.bat --test-telegram`.
6. Зроби пробну перевірку без Telegram: `run.bat --once`. Відкриється вікно; увійди, і в консолі з'явиться результат.
7. Запусти моніторинг: двічі клацни `run.bat`.

Зупинити скрипт: Ctrl+C у консолі або просто закрити консоль.

## Налаштування `config.json`

| Поле | Що означає |
|---|---|
| `service_ids` | `49` — B, механіка (авто СЦ); `50` — B, автомат (авто СЦ); `43` — B (авто автошколи). Можна кілька: `[49, 43]` |
| `region` | `"Львівська область"` |
| `department_ids` | `[]` — усі ТСЦ регіону. Львівщина: `65` Львів (Апостола, 11), `74` Львів (Богданівська, 44), `68` Самбір, `69` Стрий, `70` Шептицький |
| `min_date` / `max_date` | межі дат у форматі `"2026-10-01"`; `""` означає без обмеження |
| `interval_sec`, `jitter_sec` | пауза між перевірками (сам сайт опитує список ТСЦ кожні 30 с, тож 150 с — це м'яко) |
| `pause_between_requests_sec` | пауза між окремими запитами. **Не зменшуй нижче 5**: сайт швидко віддає `429 Too many requests` |
| `trust_allow_online_count` | `true` — дні запитуються тільки там, де `allowOnlineCount > 0`. Раз на `full_check_every_n_cycles` циклів скрипт перевіряє всі ТСЦ; якщо знайде розбіжність, сам вимкне цю оптимізацію |
| `heartbeat_hours` | повідомлення «я працюю» раз на N годин (`0` — вимкнено) |
| `browser_channel` | `""` — вбудований Chromium; `"chrome"` — встановлений Google Chrome |
| `prevent_sleep` | не дає Windows заснути, поки скрипт працює |

## Важливо

- **Не бронюй у вікні скрипта.** Бронюй у своєму звичайному браузері. Якщо відкриєш сторінку запису у вікні скрипта, він сам стане на паузу, поки ти звідти не підеш.
- У `browser_profile/` лежить твоя сесія Е-запису, а в `config.json` — токен бота. **Нікому їх не передавай** і не заливай на GitHub (`.gitignore` це вже враховує).
- Правила Е-запису: фізична особа може записатися **до 4 разів на календарний місяць**, запис індивідуальний.
- Скрипт працює тільки з **українського IP**. З іноземних серверів сайт віддає 403.
- Якщо сайт почне блокувати автоматизований браузер (постійні 403 при живій сесії), скрипт повідомить про це. Тоді користуйся офіційним @hsc_talon_bot.
