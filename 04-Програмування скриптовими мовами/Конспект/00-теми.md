# Програмування скриптовими мовами — карта тем

Позначай: `[ ]` не розібрано · `[~]` в процесі · `[x]` можу пояснити вголос

- [ ] Типи, змінні, керуючі конструкції
- [ ] Структури даних: list, dict, set, tuple
- [ ] Функції, області видимості, аргументи
- [ ] Файли, кодування, шляхи (pathlib)
- [ ] Регулярні вирази
- [ ] Обробка винятків
- [ ] Аргументи командного рядка (argparse)
- [ ] Модулі, віртуальні середовища, pip
- [ ] CSV, JSON, робота зі структурованими даними
- [ ] Мережа: requests, сокети
- [ ] Автоматизація задач ОС, планувальник
- [ ] Bash / PowerShell: конвеєри, змінні, цикли

---
Формат конспекту: один файл на тему, `NN-назва.md`. Формули — у LaTeX ($...$).
Наприкінці кожного файлу — блок «Що я маю вміти пояснити за 2 хвилини».
