## Як мене вести по цій дисципліні
- Прив'язуй завдання до реальних задач кібербезпеки: парсинг логів, перевірка хешів, масові перейменування, сканування портів.
- Пастки: кодування UTF-8/cp1251 у Windows; змінювані значення за замовчуванням в аргументах; шляхи з пробілами без лапок.

Режим допомоги за замовчуванням: **Р1 → Р2 → Р3 → Р4** (див. `00-Загальне\README.md`).
Поточний режим для цієї дисципліни: _за замовчуванням_.
