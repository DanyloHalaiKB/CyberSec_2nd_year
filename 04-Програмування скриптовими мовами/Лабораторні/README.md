# Лабораторні — правила ведення

Одна робота = одна тека: `ЛР-NN-коротка-назва\`

Усередині:
- `README.md` — умова, варіант, хід роботи, висновок (робочий чернетковий звіт)
- код / схеми / скрипти
- `screens\` — скріншоти результатів

Іменування версій: `-v2`, `-v3`. Старе не перезаписувати.
Звіт під здачу генерується з `README.md` у формат, який вимагає викладач.
